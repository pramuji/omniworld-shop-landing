# Landing page Omniworld + pelacak pengunjung

Paket statis untuk **omniworld.shop**: landing page, formulir alokasi, dan dashboard jumlah orang yang masuk ke web.

## Deploy Vercel (1 klik)

Buka: https://vercel.com/new/clone?repository-url=https://github.com/pramuji/omniworld-shop-landing

Lalu Add Domain `omniworld.shop` di pengaturan Vercel.

Dashboard statistik: `/stats` — sandi `omniworld`.
